File security

Your file password is kept in this page’s memory until you lock, switch libraries, or sign out. Locking stops transfers and closes previews. Your account password cannot recover the password of existing native or browser packages. File names, folders, sizes and tags remain visible to the server.

Browser sessions

End every browser session, including this one. App connections are managed separately in Devices.

Delete library or account

Deletion is permanent. Local app libraries are not removed, but files stored only here cannot be recovered.
