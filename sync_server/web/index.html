Connect a device

  1. Issue a token on Devices and copy it immediately.
  2. Open MegaVault Protect, choose Sync, and sign in with this account's email and password.
  3. Pick the vault and the local folder that mirrors it, then press Sync now.

The vault password is asked for on the device and is never sent here. Two devices read the same packages only when they share that vault password.
