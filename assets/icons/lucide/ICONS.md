# Lucide glyphs used by the app

Source: [lucide-icons/lucide](https://github.com/lucide-icons/lucide), fetched from the
`main` branch, ISC licence (see `LICENSE` in this directory). Regenerate the derived
assets with `python tools/icons/generate.py` — see `docs/icon-strategy.md`.

| glyph | used for |
| --- | --- |
| `plus` | add record / field / value, add files, create |
| `pencil` | rename a record, rename a key |
| `square-pen` | edit a value (opens the edit sheet) |
| `trash` | delete a record, remove a field |
| `copy` | copy a value |
| `eye` / `eye-off` | reveal / hide a secret |
| `arrow-up` / `arrow-down` | move a record up or down |
| `arrow-left` / `arrow-right` | back, move to folder |
| `arrow-up-down` | transfers |
| `chevron-right` / `chevron-down` | expand / collapse, menu affordance |
| `chevron-left` | previous, collapse the folder pane |
| `chevrons-up-down` | sort |
| `check` | save, done, allow, OK |
| `x` | close, cancel, decline, remove |
| `undo-2` | revert unsaved changes, discard |
| `refresh-cw` | refresh, sync, migrate an old record |
| `download` | check for / install an update |
| `search` | filter |
| `settings` | settings |
| `lock` | lock the vault |
| `wifi` / `wifi-off` | share over Wi-Fi / stop sharing |
| `rows-3` | details view |
| `layout-grid` | icon view |
| `list` | list view |
| `external-link` | pop out |
| `maximize` | fit |
| `scan` | fit width |
| `folder` / `folder-open` | folder, browse |
| `minus` | zoom out |
| `log-in` / `log-out` | sign in / sign out, leave |
| `rotate-ccw` | restore |
| `smartphone` / `unplug` | phone, disconnect phone |
